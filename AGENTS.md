
# Mobile Godot Development

Engine: Godot 4.5
Language: GDScript
Renderer: Compatibility
Target: iPhone Safari (Web)

Rules:
- Use Godot 4.5-compatible GDScript.
- Keep all scenes and resources under version control.
- Design controls for touchscreens.
- Support a 960x540 reference viewport.
- Prefer reusable scenes and scripts.
- Avoid C# and native GDExtensions.
- Keep web exports single-threaded.
- Do not commit secrets or .godot cache.

Before completing tasks:
- Validate the project using Godot headless mode.
- Check scene paths and script references.
- Report failed tests and limitations.
- Prepare changes for review before merge.
