# Rust City: open resource world

Implement the user's approved large resource map, location-based extraction, physical conveyors, bulk terrain clearing and the pixel/floating interface. Existing production rates and billion-scale prices remain; world income is earned by delivered sales rather than disconnected production.

- A seeded 128×128 map places natural clusters inside spaced 16×16 regions. Guarantee nearby forest, copper, coal, stone and iron plus a clear starter factory area. Forest and veins support continuous production; cleared tiles never regenerate. Render only visible cells; show a small clickable overview.
- All in-bounds land is available without district purchase. Forestry requires a tree tile; mining requires the tile's actual mineral. Other facilities and belts require empty ground. Iron remains gated by industrial progression. Preserve starter line and balance (₩500, 4s logging, 3.5s sawmill); include two starter belts so bad first purchases cannot strand the player.
- Warehouses have local inventories and optional automatic sales. Only the starter shipping warehouse sells by default. Factory input, generator fuel, construction-project deliveries and rocket deliveries move through real adjacent conveyors. Global city materials may pay construction/research costs but never feed factory recipes. Orders load at the starter shipping depot.
- Forest clearing yields two logs; ore clearing yields one unit. Charge 120% of the recovered resource's sale value, so clearing is not a money exploit. One-time clearing/demolition crews deposit salvage into the nearest warehouse; this does not supply ongoing factory recipes remotely. Clearing is permanent, cannot target occupied or unknown-resource tiles, and does not count as production. Quote a rectangular area of at most 256 tiles; confirm all cost/rewards before atomically applying.
- Conveyor tool uses two endpoint taps. Preview a resource-avoiding path and a shorter path that clears terrain. Show path arrows, costs and recovery. No building is overwritten, starter resource nodes are protected, out-of-bounds/fractional/oversized commands fail without state changes. Route placement costs ₩100 per new belt plus quoted clearing cost and commits atomically.
- Retain the original fixed-map simulation for importing existing cities and for the full reference campaign. Offer an explicit, previewed move into the open world while preserving money, inventory, entities, projects and rocket progress. Never reset existing progress silently. Fresh cities use the open world. Save and import validate world bounds, terrain, local stores and source-resource consistency.
- Mobile controls: existing floating cash/menu/zoom; two-tap construction tools, height-adjustable inspector, exact resource selection, clickable overview, nearest filtering for pixel art. Unknown resources remain `?`. No manual feed/collection or quest cards.
- Godot 4.5, Compatibility renderer, 960×540 reference, single-threaded Safari Web build. No paid assets, native extensions, cache/secrets or save-format weakening.
