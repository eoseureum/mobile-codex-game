# 첫 생산라인을 통한 규칙 발견

초반의 질문은 “돈을 어떻게 벌지?”다. 회전, 내부 재고, 매니저, 판매 정책과 먼 산업을 동시에 노출하던 구조를 바꾸고 실제 생산·가공·판매의 결과를 먼저 보여준다. 가격·생산 주기·연구 조건은 유지한다.

- 빈 도시: 나무와 첫 벌목장 가격만 전면에 둔다. 산업·기록·창고·미니맵은 쓰임이 생길 때 나타나며 메뉴 자리와 터치 영역은 이동하지 않는다.
- 첫 벌목장: 나무 → 통나무 → 동전, 제작 진행, 실제 판매 지점의 `+₩50`으로 자동 수입을 보여준다. 같은 카드에서 제재소의 판자 3개 가치 `₩300`과 연결을 포함한 가격 `₩1,600`을 비교한다.
- 첫 연결: 반투명 시설과 점선 경로는 제안이다. 누르면 총비용을 검토하고 실제 시설과 단방향 컨베이어를 함께 설치한다. 미리보기는 상태를 바꾸지 않고, 결제 불가·잘못된 위치는 부분 건설하지 않는다. 자유 배치와 개별 연결은 유지한다.
- 첫 출하: 창고 가격 `₩450`과 벨트 `₩100`을 포함해 `₩550`을 결제한다. 보관량과 기준, 초과분 판매, 판매 단가를 함께 표시한다. 실제 판매 순간에만 수입 피드백이 생긴다.
- 확장: 판자 판매 경험 뒤 산업과 미니맵을 드러낸다. 주요 시설 목록은 현재 산업에 필요한 선택지로 제한하고, 전체 시설과 상세 설정은 별도로 열 수 있다. 연구는 실제 보유 자재와 비용으로 표시한다.

지시문, 반복 퀘스트, 보상 받기, 강제 배치, 자동 구매는 추가하지 않는다. 실제 수입 피드백은 일시적인 이벤트로 전달하여 큰 도시에서 저장된 수입 기록이 시설 수만큼 불어나는 것을 피한다.

검증은 실제 비용을 지불한 첫 연결·판매, 실패한 결제의 원자성, 저장 호환, 정보 노출 순서, 생산에 따른 조작 위치 안정성, 실제 WASM의 터치 건설·저장·초반 백업 재개로 수행한다. 시뮬레이션으로 자금을 마련한 백업은 브라우저 검사의 대기 시간만 줄이며 제품에는 포함하지 않는다. 사용자 이해도 자체는 실제 플레이 관찰로 확인해야 한다.
