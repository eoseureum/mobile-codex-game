# Rust City

작은 자동 벌목장에서 시작해 로켓을 발사하는 공장 운영 게임. Godot 4.5 / GDScript / Compatibility 렌더러를 사용하며, 아이폰 Safari에서 실행할 수 있는 단일 스레드 Web 빌드를 제공합니다.

## 개발과 실행

1. 이 저장소를 내려받고 **Godot 4.5**에서 `project.godot`을 엽니다.
2. F6 또는 F5로 실행합니다. 시작 장면은 `scenes/Main.tscn`입니다.
3. 지도는 드래그로 이동하고 오른쪽 플로팅 버튼으로 확대·축소합니다. 시설을 누르면 조작 카드가 열리고, 카드 윗부분을 드래그해 높이를 바꿀 수 있습니다. 하단 메뉴의 지도 버튼을 누르면 카드가 접힙니다.

새 도시는 자원이 흩어진 **128×128 타일 월드**에서 시작합니다. 산림에 벌목장, 광맥에 해당 광물의 광산을 짓고 빈 부지에 가공 시설을 배치합니다. 모든 토지는 처음부터 사용할 수 있습니다.

새 도시는 건물 없이 **₩2,250**으로 시작합니다. 나무 타일을 골라 첫 벌목장을 지으면 4초마다 통나무 한 개가 생기고 ₩50에 현장 판매됩니다. 첫 벌목장과 첫 제재소는 현금만 필요하며, 이후 증설은 원래 자재 비용을 사용합니다. 첫 제재소는 ₩1,500, 창고는 ₩450, 컨베이어는 칸당 ₩100입니다.

통나무 생산, 가공, 운송, 판매는 자동입니다. 첫 벌목장은 가공 라인을 연결하는 동안 통나무 일부를 현장 판매해 창고 건설 전에도 수입을 유지합니다. 판자 자동 판매가 시작되면 가공 공급을 우선하고 남는 통나무만 판매합니다. 다른 벌목장에는 현장 판매가 없으며 물류망이 필요합니다. 생산 속도·판매 단가·매니저를 별도로 개선하고, 주문 출하와 도시 건설을 거쳐 산업·전력·우주 산업을 확장합니다. 미해금 항목은 `?`로 표시합니다.

- **건설 → 컨베이어 연결**: 시작과 끝을 선택하면 경로와 총비용을 미리 봅니다. 나무·광맥을 우회하거나 정리하는 경로를 고르고 연결합니다.
- **부지 정리**: 두 모서리로 영역을 선택합니다. 자원은 영구 제거되고 소량의 회수품은 공사팀이 가까운 창고에 넣습니다. 정리 비용은 회수품 판매액보다 높습니다.
- **창고**: 재고는 창고마다 따로 저장됩니다. 생산 재료·발전 연료·도시 건설 자재·로켓 부품은 연결한 운송망으로 공급합니다. 도시 합계는 건설·연구 비용 결제에만 공유합니다.
- **판매**: 처음 건설한 창고만 자동 판매가 켜져 있습니다. 다른 창고는 선택해 자동 판매와 출고 재료를 정합니다. 주문은 첫 출하 창고에 도착한 재료를 출하합니다. 첫 벌목장의 현장 판매를 제외하면 연결되지 않은 공장은 돈을 만들지 않습니다.
- **탐색**: 왼쪽 미니맵을 눌러 이동합니다. 미해금 광물은 `?`로 표시됩니다.

## Web 빌드

Godot 4.5의 Export Templates를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```sh
godot --headless --path . --editor --quit
godot --headless --path . --script tests/test_runner.gd
godot --headless --path . --script tests/test_world.gd
godot --headless --path . --script tests/test_empty_start.gd
godot --headless --path . --script tests/test_motion.gd
godot --headless --path . -- --ui-check
godot --headless --path . --script tests/test_ui_layout.gd
mkdir -p build/web
touch build/.gdignore
godot --headless --path . --export-release Web build/web/index.html
python3 -m http.server 8000 --directory build/web
```

`http://localhost:8000`에서 플레이합니다. WebGL 2를 지원하는 브라우저가 필요합니다. `file://`로 직접 열 수 없습니다. 물리적인 아이폰 Safari 검증은 별도로 필요합니다.

PR마다 GitHub Actions가 실제 Godot 엔진으로 검사하고 `rust-city-web` 빌드 파일을 첨부합니다. 검토 후 `main`에 병합하면 기존 GitHub Pages 워크플로가 웹 게임을 배포합니다. 저장소의 **Settings → Pages → Source**는 **GitHub Actions**여야 합니다. 개발·웹 배포에는 맥이 필요하지 않습니다.

## 저장과 이전

기기마다 자동 저장합니다. 관리 화면에서 JSON 백업을 내보내거나 가져올 수 있습니다. 기존 웹 게임의 **현재 공장 모드 백업(currencyVersion 2)**도 가져올 수 있습니다. 이전 클리커·채집 모드 백업은 지원하지 않습니다. 기존 Safari 저장소를 자동으로 읽지 않으므로 원래 게임에서 백업을 내보낸 뒤 여기서 가져오세요.

기존 도시는 자금과 시설을 그대로 보존하며, 빈 땅 시작은 **관리 → 새 도시 시작**에서 선택합니다. 작은 지도의 기존 도시는 **관리 → 큰 월드로 이전**을 선택하면 자금·시설·재고·진행도를 보존해 옮깁니다. 이전 전 백업을 내보내면 원래 배치를 보관할 수 있습니다. 기존 시설 배치는 유지되지만 이후 원료 공급은 실제 운송망이 필요합니다.

방치 생산은 산업 발전 후 해금되며 최대 2시간입니다. 새 웹 주소로 옮기거나 브라우저 데이터를 지우기 전에 백업을 보관하세요.

## 구조와 검증

- `scripts/core/`: 고정 0.25초 생산·물류·전력 시뮬레이션 및 저장 검증.
- `scripts/ui/`: 지도, 모바일 패널과 조작. 생산마다 버튼을 재생성하지 않습니다.
- `data/catalog.json`: 기존 게임의 가격·레시피·성장 수치를 보존한 데이터.
- `tests/reference_campaign.json`: 실제 비용을 지불하며 로켓까지 진행한 기존 웹 게임의 조작 기록. GDScript 결과와 돈·생산·판매·납품을 비교합니다.
- `tools/web_check.py`: Web 빌드 후 Playwright와 Chromium으로 실제 Godot WASM 실행을 확인합니다.

산림부터 로켓까지의 시뮬레이션은 JavaScript 래퍼 없이 GDScript로 실행됩니다. 도트 지형·시설·메뉴 아이콘은 `scripts/ui/pixel_art.gd`의 32px 원본 픽셀 작업으로 생성되며, 외부 이미지나 유료 생성 서비스를 사용하지 않습니다. 지형과 스프라이트는 최근접 필터로 표시하고 한국어 UI는 가독성을 위해 부드러운 글꼴을 사용합니다.

건물과 컨베이어는 잔디 위에 바로 표시합니다. 관리인 캐릭터 대신 톱날·광차·화로·릴·프레스·스캐너·펌프 등의 8프레임 동작으로 가동 상태를 보여줍니다. 생산 시설은 실제 제작 한 주기에 애니메이션 한 번을 맞추며, 속도 업그레이드와 전력 효율을 그대로 반영합니다. 재료가 없거나 정지한 시설은 가동 동작을 멈춥니다.

한국어 폰트 라이선스는 `assets/fonts/OFL.txt`에 있습니다.
